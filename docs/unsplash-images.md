# Unsplash images in Studio

Image fields in Studio offer Unsplash alongside the existing image sources. Search for a photo, select it, and add descriptive alternative text before publishing. Article body images also support an optional caption.

The plugin imports the selected photo into Sanity and records its Unsplash source and photographer credit on the asset. The site does not automatically display that credit, so add a credit in the image caption when appropriate. Search requests use Sanity's Unsplash integration.
